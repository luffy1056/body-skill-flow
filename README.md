# SkillFlow Journey

Build a calisthenics skill-training app called "SkillFlow". It should have a clean, dark-themed mobile-first UI with a bottom navigation bar containing these tabs: Home, Skills, Workouts, Progress, and Profile.

The Home screen should show:

- A welcome banner with the user's name and a motivational quote

- A "Today's Workout" card with skill name, sets/reps, and a "Start" button

- A "Your Skills" section showing 3–4 skill cards (e.g., Muscle Up, Planche, Front Lever) with a progress bar and current level

- A "Streak" counter showing how many consecutive days the user has trained

Use a dark background (#0f0f0f), green accent color (#00e676), and bold white typography. Use card-based layouts with rounded corners and subtle shadows.
